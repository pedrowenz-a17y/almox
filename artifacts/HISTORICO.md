# Evidências de versões anteriores

Os arquivos em `legacy/`, incluindo `api-checks.json`, `browser-checks.json`, `operations-checks.json`, `reports-labels-checks.json`, capturas e PDFs originais, foram recebidos com o projeto anterior. Eles documentam uma versão com autenticação e regras diferentes e não validam a migração para Supabase ou os novos fluxos por unidade. Os arquivos da revisão atual usam o prefixo `uca-`.

Consulte [VALIDATION-LEGACY.md](../docs/VALIDATION-LEGACY.md) para o contexto histórico e [VALIDATION.md](../docs/VALIDATION.md) para o alcance dos testes da revisão atual. Os resultados atuais devem registrar somente comandos realmente executados, com suas limitações. Nenhum arquivo deve conter senha, URL de banco com credenciais, cookie ou token de sessão.
