# Almox ERP Android 1.0.0

Instalador APK para Android 8 ou superior com WebView atualizado.

A assinatura v2/v3 foi verificada e os arquivos internos coincidem com a compilação aprovada no GitHub Actions. A checagem de instalação do arquivo assinado está sendo executada antes da publicação da versão.

O ERP precisa estar hospedado em HTTPS para funcionar com o PC desligado. O APK não contém o .env nem executa o servidor no celular. A publicação atual do domínio fornecido ainda precisa disponibilizar /login.

O backup privado da assinatura não integra este pacote público.
