# Materiais

| Arquivo | Origem e uso |
| --- | --- |
| `public/brand/uca.png` | Logo oficial incluído em `public/brand/uca-oficial.png` no ERP. Aplicado em uma placa clara, com a arte original preservada. Usado nesta apresentação do produto a pedido do solicitante. Titularidade da U.C.A. |
| `public/brand/qr-demo.png` | Etiqueta de demonstração gerada localmente. Codifica texto sintético e pode ser reproduzida com `scripts/qr.mjs`. |
| `public/fonts/manrope.woff2` e `public/fonts/dmsans.woff2` | Fontes usadas no ERP, com licenças SIL Open Font License incluídas ao lado dos arquivos. |
| `public/audio/full.m4a` e `public/audio/launch.m4a` | Trilha e efeitos sintetizados para estas montagens, por `scripts/soundtrack.py`. |
| Ícones Lucide | Pacote `lucide-react`, com a licença distribuída pelo npm. |
| Interfaces e dispositivos | Componentes React e CSS criados para o filme. Telas, ordem, materiais, contas, localizações e quantidades usam dados demonstrativos. |

O MP4 anexado e as capturas do repositório orientaram a montagem e os estados da interface. O repositório documenta a origem institucional do logo. [Referências de marca do Almox ERP](https://github.com/pedrowenz-a17y/almox/blob/98db567cd80e7923c46b19c402726891079071f5/docs/BRAND_ASSETS.md)
