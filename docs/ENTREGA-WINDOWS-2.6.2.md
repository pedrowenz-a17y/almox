# Almox ERP 2.6.2 para Windows

- Os avatares da barra superior e do menu lateral abrem Meu perfil.
- A foto pode ser adicionada, trocada ou removida. Ela fica vinculada à conta do ERP.
- O painel inclui tema, animações, escolha da tela após o login e opção de tabelas compactas no PC.

O instalador é para Windows x64. Use o arquivo `SHA256SUMS.txt` da versão para conferir a integridade. O SmartScreen pode exibir um aviso porque o arquivo está sem assinatura de editor.
