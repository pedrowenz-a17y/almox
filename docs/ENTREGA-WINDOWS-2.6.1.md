# Almox ERP 2.6.1 para Windows

- Janelas iniciais ajustadas à área disponível na tela.
- O aplicativo verifica se a página abre antes de salvar um novo endereço.
- No modo online, as telas acompanham a versão publicada no endereço configurado.

O instalador é para Windows x64. O arquivo `SHA256SUMS.txt` acompanha a versão para conferência de integridade.
